 # React Route advanced 

        Imagine your app is a city.
        <BrowserRouter> = the GPS/navigation system
        <Routes> = the map of all roads
        <Route> = a specific road
        <Link> = a road sign
        useNavigate() = a taxi that changes location
        useParams() = reads information from the current address

        Without the GPS (BrowserRouter), none of the other navigation tools know where you are.

# Rule to remember
1. BrowserRouter is the provider that gives routing capabilities to all components inside your React app. Without it, React Router components and hooks cannot work.
